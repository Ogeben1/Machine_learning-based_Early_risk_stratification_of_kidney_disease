# Machine_Learning-based_Early_risk_stratification_of_kidney_disease

### Project Overview

Chronic kidney disease (CKD) is said to be one of the underdiagnosed ailments globally and can progress without obvious symptoms, so identifying adults at elevated risk before advanced disease may help prioritize follow-up testing and clinical review. Recognized risk factors include Diabetes, high blood pressure, heart disease, and family history. Kidney assessment commonly uses blood-based eGFR serum creatinine and urine albumin tests. This project will develop and evaluate a machine-learning model  that estimates an adult patient’s risk of kidney disease using routinely available information. 

### Tools and Technologies used:
Python 3 for data processing, modeling, and reproducible analysis.
Pandas and NumPy for data cleaning, date handling, feature engineering, and numerical operations.
Matplotlib and Seaborn for exploratory plots and evaluation figures.
Scikit-learn for preprocessing pipelines, train/validation design, logistic regression, random forest or gradient-boosted baselines, and evaluation. scikit-learn permutation importance for model interpretation, used as descriptive tools rather than proof of causal effects.
JupyterLab for analysis and documentation; Git for version control.
### Project Objectives

1.Assess whether demographic, clinical, and kidney-function measurements available at baseline can identify patients at increased risk of CKD.
2.Compare an interpretable statistical baseline with selected machine-learning models.
3.Evaluate discrimination, calibration, and performance at clinically relevant operating thresholds, with attention to missed high-risk patients and unnecessary alerts.
4.Examine whether model performance varies across key demographic and clinical subgroups.
